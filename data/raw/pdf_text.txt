4. System Architecture & ETL Pipeline
The project follows a classic data engineering architecture: Extract ΓåÆ Transform ΓåÆ Load ΓåÆ Analyse ΓåÆ
Visualise. This mirrors real-world fintech data pipelines used at companies like Zerodha, Groww, and Paytm
Money.
LAYER 1: DATA SOURCES (Extract)
I AMFI Daily NAV TXT (amfiindia.com/spages/NAVAll.txt)
I AMFI Historical NAV API (portal.amfiindia.com/DownloadNAVHistoryReport_Po.aspx)
I mfapi.in REST API (GET /mf/{scheme_code} ΓÇö JSON, no auth required)
I AMFI Monthly Notes PDF (amfiindia.com/research-information/amfi-monthly)
I NSE/BSE Bhavcopy CSV (nseindia.com/reports)
I Pre-packaged CSV datasets provided with this project
LAYER 2: DATA PROCESSING (Transform)
I Python (Pandas) ΓÇö parse, clean, reshape, merge datasets
I Handle missing NAV values (weekends/holidays ΓåÆ forward-fill)
I Compute derived fields: daily returns, rolling averages, CAGR
I Normalise fund names (AMFI naming inconsistencies)
I Validate AMFI codes against master list
I Enrich transactions with fund metadata (join on amfi_code)
LAYER 3: DATA STORAGE (Load)
I SQLite (development) or PostgreSQL (production)
I 5-table star schema: dim_fund, dim_date, fact_nav, fact_transactions, fact_performance
I Indexed on amfi_code, date for fast query performance
I CSV flat-file backup for Tableau / Power BI direct import
LAYER 4: ANALYTICS (Analyse)
I Jupyter Notebooks for EDA (Matplotlib, Seaborn, Plotly)
I Risk metrics: Sharpe, Sortino, Alpha, Beta, Max Drawdown, VaR
I Benchmark comparison: rolling 3-month alpha vs Nifty 100
I Cohort analysis: investor tenure vs average SIP amount
I Geographic heatmap: T30 vs B30 city AUM contribution
LAYER 5: VISUALISATION (Dashboard)
I Power BI / Tableau Desktop dashboard
I 4 report pages: Fund Overview, Performance, Investor, Industry Trends
I Slicers: Fund House, Category, Date Range, State
I KPI cards: AUM, SIP Inflow, Folio Count, Top Performer
I Export to PDF for stakeholder distribution
